# 随机自动抽奖与运行日志

每天为每个账号创建早间（08:00–09:00）、午间（13:00–14:00）、晚间（18:00–19:00）三条随机执行计划。每条计划只执行一次，计划与执行结果持久化到现有状态文件，服务重启后不重复抽奖。

调度器每分钟检查已到期计划，调用既有 `DrawAvailable`。无可用次数记为跳过；认证或接口异常记为失败并保存脱敏错误，不在当天自动重试。每次执行写入账号、窗口、计划/实际时间、结果、奖品摘要或错误信息。

日志保留 7 天。工作台提供只读系统运行日志，按时间倒序显示自动抽奖的成功、跳过和失败；不返回密码、Cookie、Token、幂等键或原始上游响应。
